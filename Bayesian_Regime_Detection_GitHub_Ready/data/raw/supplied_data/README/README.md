# SYNTHETIC DEMO DATA — NOT REAL MARKET DATA

Purpose: educational software development, exploratory analysis, dashboard testing, and model-pipeline testing only.

All observations in this package are programmatically generated to resemble broadly plausible Indian-market time-series formats and ranges. They are not sourced from NSE, RBI, AMFI, NSDL, FRED, or any other provider. Do not use them for investment decisions, performance claims, academic empirical findings, or factual market analysis.

Coverage: business days from 2010-01-01 through 2026-09-09 for daily files; monthly and quarterly files use their respective typical frequencies. Random seed: 20260909, allowing deterministic reproduction.

Derived files are simulated too; they are not calculated from constituent security histories.
